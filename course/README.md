# Курс NXAI — материалы

Четыре сборки, каждая доведённая до продакшена, а не до демо. Формат урока
повторяет курс, с которого всё начиналось, с одним намеренным отличием:
**первый прилагаемый файл — журнал ошибок, а не расшифровка удачного
планирования.**

## Почему журнал ошибок идёт первым

Готовый workflow показывает, что получилось. Он не показывает, где было
потеряно три дня. Почти всё, что ломалось в этих сборках, **не падало с
ошибкой** — оно выглядело как что-то другое, обычно как проблема промпта, и
утягивало в правки, которые не могли сработать.

Студент, прочитавший журнал до начала, задаёт Claude Code правильный вопрос
сразу. Это и есть разница между шестью часами и тремя днями.

## Структура

```
course/
  build-1/
    lesson.ru.md                    урок (русский, основной)
    lesson.en.md                    урок (английский)
    1. Журнал сборки.docx           что сломалось, почему, и что сказать сразу
    2. Бриф.docx                    бриф, из которого собран workflow
    3. Настройка ВКонтакте.docx     сообщество, токен, Callback API
    4. n8n Workflow.json            готовый workflow на импорт
```

## Правило, которое легко нарушить

**Урок может ссылаться только на свои приложения.** У студента нет этого
репозитория — у него четыре файла и больше ничего. Ссылка на
`docs/05-vk-setup.md` или на `expenses-schema.csv` для него просто обрывается,
и сборка встаёт.

Перед публикацией любого урока:

```sh
grep -noE '`[^`]*\.(md|js|py|csv)`' course/build-N/lesson.*.md
```

Каждое совпадение обязано быть именем приложенного файла. Всё остальное —
либо становится приложением, либо вписывается в урок прямо текстом.

учит и её пробелам тоже.

## Стек: местный и глобальный

Сборки живут на российской инфраструктуре — ВКонтакте, Yandex AI Studio,
самостоятельный хостинг. Это не предпочтение: Telegram не работает с
российского сервера, а данные клиента не должны покидать страну (152-ФЗ).

**Паттерн переносится куда угодно, поставщики меняются.** В английском уроке
у каждого компонента назван глобальный заменитель. Полная карта —
`docs/ru-stack-map.md`.

Отдельный глобальный трек (Telegram + OpenAI + n8n Cloud) появится только
тогда, когда эти сборки будут действительно собраны и протестированы на том
стеке. Урок с непроверенным workflow дороже, чем его отсутствие.
